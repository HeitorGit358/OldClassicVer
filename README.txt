How to install OldClassicVer:

1. Run the TAKEOWNERSHIP.bat
2. Copy the contents of your prefered version (ex: seven)
2. Replace C:\Windows\Branding\basebrd\en-US\basebrd.dll.mui, C:\Windows\Branding\basebrd\basebrd.dll, C:\Windows\System32\en-US\shell32.dll.mui, and C:\Windows\System32\winver.exe by the ones on the paste you choosed
3. Run "winver.exe" and see if was applied
